## Overview

DunasTech is the **Observatório Inteligente do Turismo** for Rio Grande do Norte, implemented as a **Next.js 16 (App Router, React 19) web app** — not the earlier Streamlit MVP. It serves two surfaces: a mobile-first tourist experience (B2C/C2C — "the sensor") and a management observatory (B2G). External services (Firebase, Gemini, Apify, Carto basemaps) are all optional; the app degrades gracefully to mock/localStorage.

## Data Flow

1. Tourist submits an evaluation (`/avaliar`) → `addFeedback` → Firestore `feedbacks` (or `localStorage` fallback).
2. Feedbacks feed the **ISA** (`calcularISA`) surfaced on home, ranking, and the gestão dashboard.
3. Gestão consumes feedbacks in real time (`subscribeFeedbacks` / `onSnapshot`), plus social sentiment via `/api/scraper` and AI diagnostics via `/api/gemini`.

## Conventions

- **Naming:** PT/EN mix in domain data; components PascalCase; utils camelCase.
- **Structure:** thin server `page.tsx` + fat `'use client'` components; maps via `dynamic(..., { ssr: false })`.
- **Testing:** Vitest (`src/lib/utils.test.ts`, `src/data/mockData.test.ts`).
- **Commits:** `type(scope): description`.
